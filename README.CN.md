## 摘要
利用WACCM-X模拟和流星雷达观测研究2022年汤加火山爆发在MLT区域的扰动

利用高分辨率全大气群落气候模式及热层/电离层扩展版本(WACCM-X)和不同纬度的流星雷达来模拟和观测2022年1月15日汤加火山爆发的大气响应。具体使用了位于漠河(53.5°N, 122.3°E)、北京(40.3°N, 116.2°E)、蒙城(33.3°N, 116.5°E)、武汉(30.5°N, 114.2°E)和三亚(18.3°N, 109.6°E)的流星雷达。将模拟结果与地基流星雷达观测结果进行比较,研究中层和低热层(MLT)区域的风场、中性密度和温度扰动。通过结合模拟和观测,我们旨在阐明汤加火山爆发引发的MLT区域大气扰动的动力学机制。
